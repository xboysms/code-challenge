# Express CRUD API (TypeScript)

## 📌 Setup Instructions

### 1️⃣ Install dependencies
```sh
npm install
```

## Run
```sh
npm run dev
```

## API Endpoints
```sh
POST /items → Create an item
GET /items → Get all items
GET:id /items/:id → Get single item
PUT /items/:id → Update an item
DELETE /items/:id → Delete an item
```
